# Bravura note symbols

Original Bravura outlines from Steinberg, exported as SVG using fontTools.
Source: https://github.com/steinbergmedia/bravura/tree/37b194378b710cc40e406ab6c4b07608bb9548ae
Font: `redist/otf/Bravura.otf`
License: SIL Open Font License 1.1; see LICENSE.txt.

SMuFL: whole E1D2, half E1D3, quarter E1D5, eighth E1D7, sixteenth E1D9.
All symbols use the same 1200-unit viewport and scale, with individually centered bounds.
Currently used only by GuitarJemp.

Modifier buttons: dotted-quarter.svg combines noteQuarterUp (E1D5) with
augmentationDot (E1E7); triplet.svg combines tuplet3 (E883, at 1.5× scale)
with a drawn tuplet bracket. Both use a 1200-unit viewport.

Chord button: triad.svg combines three Bravura noteheadBlack (E0A4)
contours a third apart with a shared upward stem, in a 1200-unit viewport.
